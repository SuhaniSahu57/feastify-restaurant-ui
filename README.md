## 📌 Project Overview

**Feastify** is a modern restaurant website UI created to provide an attractive,
responsive and user-friendly browsing experience.

The project focuses on designing a complete restaurant interface with a
structured navigation bar, promotional offers, categorized food menu,
table booking section, location map and a professional footer.

This project was developed as a **frontend web development project** to
practice and demonstrate HTML, CSS and Bootstrap skills.

---

## ✨ Key Features

### 🧭 Navigation
- Clean and responsive navigation bar
- Restaurant branding with custom typography
- Navigation links for major website sections
- Responsive mobile navigation using Bootstrap

### 🍔 Hero Section
- Attractive restaurant hero section
- Restaurant introduction and promotional content
- Prominent "Order Now" call-to-action

### 🎁 Special Offers
- Promotional food offer cards
- Discount highlights
- Food imagery with hover effects
- Responsive two-column layout

### 🍽️ Food Menu
- Dedicated restaurant menu section
- Multiple food categories
- Food cards with:
  - Food image
  - Item name
  - Description
  - Price
  - Cart icon
- Hover effects on food images
- Responsive card grid

### 📋 Table Booking Section
- Customer name field
- Phone number field
- Email field
- Number of persons selection
- Date selection
- Book Now button

### 📍 Location
- Integrated Google Maps location section
- Responsive map container

### 🦶 Footer
- Contact information
- Restaurant information
- Opening hours
- Quick navigation links
- Social media icons
- Copyright and developer information

## 📱 Responsive Design

Feastify is designed with responsive layouts using **Bootstrap's grid system**
and custom CSS media queries.

The interface adapts to different screen sizes, including:

- 💻 Desktop
- 📱 Mobile
- 📟 Tablet-sized screens
